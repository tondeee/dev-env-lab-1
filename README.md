# Open Data AI Analytics

## Мета проєкту
Метою цього проєкту є використання Git для управління версіями під час роботи над завданням з аналізу даних, дотримання правильної структури репозиторію та відпрацювання базових команд (branching, merging, resolving conflicts).

## Джерело відкритих даних
Набір даних: [Customer Personality Analysis](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis)

## 3 питання/гіпотези для аналізу
1. **Гіпотеза щодо доходу та витрат**: Клієнти з вищим рівнем освіти мають вищий рівень доходу і, відповідно, витрачають більше коштів на преміальні категорії товарів (наприклад, вино чи м'ясо).
2. **Гіпотеза щодо сімейного стану**: Клієнти з дітьми в родині здійснюють покупки рідше, але мають більшу частку витрат на товари першої необхідності у порівнянні з самотніми клієнтами без дітей.
3. **Гіпотеза щодо ефективності рекламних кампаній**: Клієнти, які прийняли пропозицію в першій рекламній кампанії, з більшою ймовірністю відгукнуться на наступні кампанії, ніж ті, хто не брав у ній участі.

## Структура репозиторію проекту
- `data/`: Дані для аналізу (локальні).
- `notebooks/`: Jupyter-ноутбуки.
- `src/`: Скрипти на Python.
- `reports/figures/`: Графіки та звіти (результати).
